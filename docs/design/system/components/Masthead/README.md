# Masthead

The top bar on every page: the TopicTutor name, account navigation and the theme button, closed by the double rule.

- Signed out: Log in, Register (outlined), theme.
- Guest with progress: a polite italic line ("Your 1-day streak lives in this browser.") and "Keep it · create account". On phones the line collapses to the button.
- Signed in: Today, Library, Stats (current page underlined in `accent`), theme, and the account button showing the photo or the first initial. The menu shows the name (or email if there is no name), the email, Profile and Sign out. Long names truncate with an ellipsis.
- On phones the signed-in links move to a bottom bar of three tabs; the name, theme and account stay on top.
- In the daily session and tests the masthead is replaced by a compact bar: close, name, theme.
