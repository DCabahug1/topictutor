# Notice

A block for things that went wrong or ran out: generation failures, guest limits, missing pages and expired links.

- Error: `incorrect-wash` with a 3px `incorrect` top rule, cross glyph, mono kicker, a serif sentence, and two actions: retry and a way to leave.
- Limit and info: `paper-raised` with an `ink` top rule. Always offers a next step (the sample series for guests).
- Not found and expired links use the same block as a full page, centred in the reading column.
- Headline says what happened in plain words. Body says what was kept and what to do. No error codes.
